Amp Accessible 2.41.58 - Actualizaciones GitHub Automáticas JAWS
NOVEDAD 2.41.58: se incorpora el flujo de publicación automática mediante GitHub Actions y GitHub Releases. Al publicar una versión nueva, GitHub puede compilar Windows x64 autocontenido, generar el instalador, crear paquetes incrementales .gdmupdate y publicar update-channel.json con verificación SHA-256.
NOVEDAD 2.41.58: las compilaciones generadas por GitHub reciben automáticamente el canal HTTPS del repositorio. El botón Buscar actualizaciones puede usar ese canal sin editar manualmente la publicación.
IMPORTANTE 2.41.58: no se modifica ningún algoritmo de audio. Batería, bajo, piano, Hammond, amplificadores, NAM, IR, efectos, escenas, F12 y looper quedan exactamente sobre la base estable 2.41.57.
